# YouTube Clone

A simple YouTube homepage clone built using HTML and CSS. This project replicates the layout and styling of YouTube's homepage to practice front-end web development skills.

## Features
- Responsive design
- Navigation bar with search functionality
- Video thumbnails and titles
- Sidebar with categories
- Footer section

## Technologies Used
- HTML
- CSS (Flexbox & Grid)

## How to Run the Project
1. Clone the repository:
   ```sh
   git clone https://github.com/grimransh/youtube-clone-html-css.git
   ```
2. Navigate to the project directory:
   ```sh
   cd youtube-clone-html-css
   ```
3. Open `index.html` in your browser.
